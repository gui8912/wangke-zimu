# 简称膨胀表（v1.5，2026-11-09 扩充）
# 格式：简称=>全称。一行一条，# 开头为注释。
#
# 为什么单独一张表：
#   简称与全称之间没有字符相似性（实测 GSP 在全术语表里模糊匹配只有 29 分），
#   任何模糊算法都认不出来，只能显式映射。
#
# 替换规则：
#   英文缩写按「前后不是字母数字」整词匹配 —— 支持「GSP认证」「按GSP要求」，
#   但不会把 GDP / GSPX 误伤。
#   中文简称按整词直接替换（中文没有词边界）。
#   长简称先替换：所以「医疗器械GMP」会先于「GMP」命中。
#
# 使用建议：只放**无争议**的简称。改错术语比不改更糟，
#   有歧义的（如「两品一械」在不同文件里所指范围不同）宁可不放，
#   留在下方注释区由人工确认后再启用。
