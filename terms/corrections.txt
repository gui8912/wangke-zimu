# ── 域内仍有歧义，暂不启用（逐条写明为什么不收）──
# 处于药品=>储运药品  「处于药品短缺/研发阶段」是域内正常表达，改了会错
# 备安=>备案          「准备安全资料」「储备安全库存」含「备安」，域内常见
# 双剂=>栓剂          「双剂型」在疫苗/复方制剂语境可能出现
# 泡制=>炮制          「泡制药材」「泡制酒」是正常表达，不是错字
# 炮炙=>炮制          「炮炙」是中药学传统术语，本身可能就是原文
# 列要=>劣药          「列要点」是培训稿里的常见说法
# 储备=>贮藏          语义不同（储备是数量，贮藏是条件），不能全局替换
# 代理采购=>带量采购  语义不同（一个是渠道，一个是定价机制）
# 批纪=>批次          低频，先观察；贸然替换的收益小于风险
