网课转字幕工具（药品监管网课语音转字幕 / 文稿）

【用途】
把国内中文网课（药品、医疗器械监督管理等专业）的录音 / 录像，转成字幕（SRT / VTT）
或可编辑文稿（TXT / DOCX）。
- 适配专业术语，自动清理口语词（语气词、冗余、填充词等 100+ 条规则）
- 精度优先（Qwen3-ASR-1.7B，纯 CPU 约 1.37× 实时，1 小时课约 44 分钟），可接受慢
- 自带网页操作台：口语词编辑、播放器逐句校对、查找替换、截图、暗色护眼主题、七遍改稿
- 默认纯本地（音视频不出本机）；1.3 起可选云端识别源，内容不涉密时可用

【1.3 可插拔识别源与双轨整理稿（2026-11-08）】
- 用户确认：音视频可出本机、可在云端运行、内容不涉密
- 调研 DoubaoVoiceIME / 豆包输入法「智能文字整理」/ 微信输入法「文字整理」后，
  不照搬逆向 SDK，改接官方云 API；新增 asr_providers.py 抽象层
- 双轨：字幕轨 = 识别原文 + 字级时间戳（SRT/VTT/波形/对齐，一字不改）；
  讲稿轨 = 云端顺滑/口语转书面语文本（七遍改稿用，允许改措辞）
  理由：整理稿改过字，直接做字幕会打断 align.py 的字级对齐、音画不同步
- 顶栏新增「识别源」下拉：本地 Qwen3 / Paraformer 为默认；腾讯云、火山豆包
  本版只留骨架与字段映射，未配密钥时选项置灰并写明原因，提交拦为 400
- 「整理稿对比」弹窗：左原文 / 右整理稿逐段标差异，可一键恢复识别原稿、
  复制整理稿、用整理稿另起一份改稿（不覆盖 v0 原稿）
- 勾选「云端整理稿」后跳过本地 101 词清理（默认不勾），
  避免同一次识别产出两份互相竞争的整理稿
- 密钥只走环境变量，不写仓库：ASR_TENCENT_SECRET_ID / _SECRET_KEY / _APPID，
  ASR_VOLC_APP_KEY / _ACCESS_KEY / _SECRET_KEY；ASR_PROVIDER 可改默认源
- 术语保护：云端热词每词 <10 字，超长监管术语会被剔除，需人工复核；
  ITN 可能把「第一百二十条」写成「第120条」，必须保留轨 A 原文
- 回归：samples/test_providers_v13.py（18 项），既有全套回归全绿

【使用方法】
方式一 · 服务台（推荐）
1. 双击桌面「服务台」快捷方式，或运行 D:\Tools\服务台\启动服务台.bat
2. 在「自建应用」分组找到「网课转字幕」，点「启动」；浏览器自动打开 http://127.0.0.1:7870/
3. 停止：在服务台点「停止」，或直接关掉启动窗口

方式二 · 直接双击
- 双击「启动网课转字幕.bat」（原有的 启动界面.bat 亦可），浏览器自动开 7870
- 关闭该窗口即停止服务

方式三 · 命令行（批量 / 无界面）
- 单文件转写并清理：  python transcribe.py -i "课程.mp4" --clean
- 指定输出目录：      python transcribe.py -i "课程.mp4" -o out\
- 列出可用模型：      python transcribe.py --list-models
- 指定识别源：        python transcribe.py -i "课程.mp4" --provider local-qwen3
- 云端源用整理稿：    python transcribe.py -i "课程.mp4" --provider tencent-cloud --use-script-track
- 仅清理已有文稿：    python clean_transcript.py 输入.txt
- 七遍改稿：          python revise.py 输入.txt

网页端功能
- 上传音频 / 视频 → 自动识别 → 字幕时间轴
- 「口语词」编辑窗口：空格分隔词条，实时增删规则
- 「识别源」下拉：默认本地；云端未配置或待接入时置灰并写明原因
- 「整理稿对比」：仅云端整理稿可用，逐段 diff + 一键恢复识别原稿
- 播放器：点时间轴跳到对应字幕，逐句听校
- 查找替换、截图导出、暗色护眼主题（?theme=dark 或界面内切换）
- 导出场：SRT / VTT / TXT / DOCX

【原理步骤】
1. 识别：Qwen3-ASR-1.7B（bf16，本地 ModelScope 模型，D:\AI\models\modelscope）出文本；
   配 Qwen3-ForcedAligner-0.6B 出字级时间戳，按 jieba 词边界切句（≤20 字/行，≤28 字/句）
2. 清理：clean_transcript.py 按 filler_words.json 五组顺序
   （组合填充 → 口头冗余 → 句尾确认 → 语气词 → 句首填充）删除 / 改写口语词，
   保留守卫词（嘛 / 哈等只在词尾删）
3. 改稿：revise.py 七遍流程（P1–P7）无状态执行，逐遍提升书面度，最后 to_docx() 套公文版式
4. 交付：server.py 把以上封装成网页 API；前端单文件交互

备选引擎：Paraformer（约 13.5× 实时，更快但需热词），可用 --model 切换。
