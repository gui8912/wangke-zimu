哪些词不删、只给建议（7 组判别）
  • 我们／咱们 单位自称（后接监管、要求、局、单位、规定…）→ 建议改「我局／本单位」，不删；泛称引导（我们来看…）→ 删「我们」，保留「来看…」
  • 这个／那个 后接名词 → 保留；后接逗号顿号 → 无论位置都删
  • 实际上／其实／事实上 后接「是、但是、而是、并非、相反」→ 保留；充当口头禅 → 删
  • 基本上／大概／差不多 后跟数字、法条、金额 → 保留并回听核对；否则删
  • 应该讲／可以说／换句话说 有解释功能 → 建议精简为「即」；当填充 → 删
  • 大家可以看到／请注意 课件引导句 → 建议精简为「注意／参见」；同一篇超过 2 次的部分删
  • 嘛／哈 只在句尾删，「干嘛」「哈哈」「喇嘛」不动
