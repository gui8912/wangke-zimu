批量添加识别任务说明（夜间 / 出差无人值守）

【用途】
一次把几十节课的音视频排进转写队列，晚上或出差时让机器自己跑；
支持定时开始、暂停/继续、失败自动重试、文件夹监控、优先级调整、
重启续跑、跑完汇总报告，识别中自动阻止 Windows 休眠。

【文件清单】
- 启动批量任务.bat   双击打开命令行入口（纯 ASCII，避免 cmd 乱码）
- batch_add.py       批量入队脚本（同盘硬链接，不重复占用磁盘）
- 批量任务说明.txt   本说明
- media/inbox/       监控目录，把课件丢进去即可自动入队
- config/queue.json  队列状态（暂停/定时/重试/监控）；不含密钥，不入库
- out/队列报告.md     队列跑空时自动生成的汇总

【使用方法】
1) 图形界面（推荐新手）
   打开网页 → 左侧「任务」卡片 → 展开「批量 · 夜间无人值守」
   - 点「批量添加课件…」一次选多个文件，或直接把多个文件拖到上方虚线框
   - 「定时开始」选好日期时间后点「设定」；到点自动开跑
   - 「暂停队列 / 继续队列」随时切换；队列条目可用 ↑ ↓ 调整先后
   - 勾「文件夹监控」后，往 media/inbox 放文件会自动入队
   - 「失败自动重试」建议 1 次；「跳过已转录」建议常开

2) 命令行（适合计划任务 / 出差前一键排好）
   python batch_add.py "D://课程//*.mp4" "E://录音//第一节.m4a"
   python batch_add.py "D://课程" --at "22:30"    今晚 22:30 开跑
   python batch_add.py "D://课程" --at "+60"      60 分钟后开跑
   python batch_add.py --status                   查看队列
   python batch_add.py --scan                    只扫描 inbox
   双击 启动批量任务.bat 后可把参数直接敲进去。

3) Windows 计划任务（真正无人值守）
   程序：C://Users//guiker//.workbuddy//binaries//python//envs//default//Scripts//python.exe
   参数：batch_add.py "D://课程" --at "22:30"
   起始位置：本工具目录
   注意：服务需先启动（启动界面.bat 或服务台），计划任务只负责排队。

【原理 / 步骤】
1) 脚本把文件以 NTFS 硬链接方式放进 media/inbox（同一块盘零拷贝、
   不额外占空间；跨盘才真正复制）。
2) 调用 /api/queue/scan，服务端逐个登记并调用统一的建任务入口，
   保证与网页端单个上传的模型、语种、清理、术语开关完全一致。
3) 同名同大小且已完成 / 已排队 / 识别中的文件自动跳过，重复拖入不白跑。
4) 队列串行执行（本机 CPU 跑一份识别已接近满载，多份并行只会互相拖慢）；
   失败的任务自动重排到队尾，次数由「失败自动重试」控制。
5) 队列状态落盘，服务重启后排队中的任务自动续跑；识别中被打断的
   标为「中断」，可手动重试。
6) 识别中每 20 秒调用 SetThreadExecutionState 阻止系统休眠，
   跑完立即释放，不改电源计划。
7) 队列清空时写 out/队列报告.md：每节课状态、耗时、字数、失败原因。

【重要提醒】
- 1 小时课件本地识别约 1.4 小时（2 路分片并行后约 45–70 分钟），
  10 节课请按整晚估算；北方冬天注意散热。
- 合盖、断电、系统更新重启会中断任务；重启服务后排队任务会自动续跑，
  正在识别的那一条需要点「重试」。
- 云端模型只用于「LLM 润色」讲稿，音视频识别始终在本机，不出机。
- 删除 / 清空任务只删任务记录，out/ 里的字幕稿与 media/ 里的源音视频
  一律保留；本工具不提供自动删除源文件的入口，需要整理请手动操作。
- config/ 目录含 API Key，已加入 .gitignore，切勿手动提交或外发。

【备份建议】
- 定期把 out/ 目录（字幕、讲稿、报告）同步到 NAS；media/ 源文件
  可从原始课程重新导入，不必长期保留两份。
- 改队列规则前先复制一份 config/queue.json；误删后可改回默认值。
